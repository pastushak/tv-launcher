# TV Лаунчер

Власний легкий лаунчер для Android TV. Написаний для Xiaomi Mi TV P1 (MiTV-MSSP1), але працює на будь-якому телевізорі чи приставці з Android TV 5.0+.

## Можливості

- годинник і дата українською;
- ряд «Улюблене», порядок якого можна змінювати;
- усі застосунки сіткою, з банерами ТВ-застосунків і збільшенням плитки під фокусом;
- приховування непотрібних застосунків;
- 6 фонів-градієнтів і вибір кількості колонок (4–7);
- швидкий перехід до «Про застосунок», видалення, системних налаштувань;
- необов'язкова служба, щоб кнопка Home завжди вела на цей лаунчер;
- без реклами, без доступу до інтернету, без сторонніх бібліотек.

## Керування пультом

| Кнопка | Дія |
|---|---|
| OK | відкрити застосунок |
| Затиснути OK або «Меню» | дії: додати в улюблене, перемістити, сховати, видалити |
| Назад / Home | повернутися на початок екрана |

## Як отримати APK (через GitHub)

1. Створіть на GitHub новий репозиторій, наприклад `tv-launcher`.
2. Завантажте в нього **весь вміст** цієї теки, разом із прихованою текою `.github` (Add file → Upload files, перетягніть файли й теки).
3. Відкрийте вкладку **Actions**: збірка запуститься сама й триватиме 3–5 хвилин.
4. Готовий файл `TvLauncher-N.apk` з'явиться у **Releases** (праворуч на головній сторінці репозиторію).

Кожна нова збірка підписана тим самим ключем (`app/launcher.keystore`), тож оновлення встановлюється поверх попередньої версії без видалення.

## Встановлення на телевізор

**Через флешку.** Скопіюйте APK на флешку, вставте в телевізор і відкрийте файл через файловий менеджер (наприклад, X-plore або File Commander з Google Play). Система попросить дозволити встановлення з невідомих джерел для файлового менеджера, дозвольте.

**Через ADB по мережі.** Увімкніть на телевізорі «Для розробників» (Налаштування → Параметри пристрою → Про пристрій → 7 разів натиснути «Збірка»), потім увімкніть «Налагодження USB» / «Налагодження через мережу».

```
adb connect <IP-адреса телевізора>
adb install -r TvLauncher-N.apk
```

## Щоб кнопка Home відкривала цей лаунчер

**Спосіб 1 (рекомендований, без ADB).** Увімкніть службу спеціальних можливостей:
Налаштування → Параметри пристрою → Спеціальні можливості → «TV Лаунчер: кнопка Home» → Увімкнути.
Служба реагує лише на появу стандартного лаунчера й одразу відкриває цей.

**Спосіб 2 (через ADB, радикальніший).** Вимкнути стандартний лаунчер:

```
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

Повернути назад:

```
adb shell pm enable com.google.android.tvlauncher
```

Увага: якщо після цього видалити TV Лаунчер, у телевізора не буде головного екрана. Спершу поверніть стандартний.

## Збірка в Android Studio

Відкрийте теку проєкту в Android Studio (Hedgehog або новіша), дочекайтеся синхронізації Gradle і виберіть Build → Build App Bundle(s) / APK(s) → Build APK(s).

## Структура

```
app/src/main/java/ua/pastushak/tvlauncher/
  MainActivity.kt       головний екран, меню, налаштування
  AppTile.kt            плитка застосунку
  AppRepository.kt      пошук встановлених застосунків
  Prefs.kt              збереження улюбленого, прихованого, фону
  Backgrounds.kt        фони-градієнти
  HomeButtonService.kt  служба для кнопки Home
```
